Help

Getting Started

This extension helps you extract and process names from search results and find matching email addresses.

Features

  • Extract Names: Extract names from Google, ContactOut (CO), or FastPeopleSearch (FPS) search results.
  • Apply Bark Data: Automatically fill in search parameters from Bark dashboard pages.
  • Search & Process (Unite4Heritage): Open Unite4Heritage name pages, paginate when needed, and filter by email/phone patterns.
  • Search & Process (ZabaSearch): Open ZabaSearch result pages for each extracted name and filter scraped contact lines by your email pattern (same flow as the standalone NPD extension).
  • Search ThatsThem: For each name in the list, opens a ThatsThem name URL (/name/First-Last/City-ST, e.g. thatsthem.com/name/…), reads each person record card separately. The email pattern decides which cards qualify as a match. With email only, every phone on those cards is listed when present. If you add a phone pattern, only numbers on the same card that match it are listed; if none match, matching emails for that card still appear (the phone pattern never hides an email hit).
  • Unite pagination: Use “Stop after first page with a match” for speed, or turn it off to scan every page and collect all matches.
  • Result vs profile crawl: “Result pages only” uses listing cards only. Turn it off to load every result page, then open each profile/detail (/pname/) link and merge that data before matching.

OpenAI API Key

To use the name extraction feature, you need to provide your OpenAI API key in the Settings page. The key is stored locally in your browser and is used to extract names from search results.

How to get an API key:

  1. Visit OpenAI Platform
  2. Sign in or create an account
  3. Create a new API key
  4. Copy the key and paste it in the Settings page

Usage Instructions

  1. Go to the Settings page and enter your OpenAI API key
  2. Fill in the search parameters (First Name, Email Pattern, City, State) or click "Apply Data from Bark" to apply data from Bark dashboard
  3. Navigate to a Google, ContactOut, or FastPeopleSearch page
  4. Click the appropriate extract button (Google, CO, or FPS)
  5. Review the extracted names in the text area
  6. Click "Search & Process (Unite4Heritage)", "Search & Process (ZabaSearch)", or "Search ThatsThem" to find matching results

Email Pattern

The email pattern filters results. Rules:

  • * matches exactly one character (same length as that segment in a real address).
  • The local part and domain part (before and after @) must be the same length as the candidate; only positions where you put a letter or digit are checked, except on ThatsThem redacted rows (see below).
  • Example: j******e@e*****e.com matches john.doe@example.com (same lengths; literals line up).
  • ZabaSearch: if your pattern looks like a full address from Bark, the part before @ may be replaced with stars for domain-led matching (unchanged).
  • ThatsThem (redacted): when the page shows l then a redacted block with --length: 11 then @hotmail.com, the local length is 1 + 11 = 12. That is matched against your pattern local length; visible characters (e.g. the leading l) must match your pattern at those indices. Characters inside the redacted span are not read from the page, but the span length must make the total local length match.

Phone pattern (ThatsThem)

For US numbers, patterns like (909) ***-**** are matched against the 10 digits of the phone (punctuation ignored): * is one digit. So 909-674-4035 matches that pattern; 916-337-9035 does not. If your pattern does not contain exactly 10 digits and stars total, matching falls back to same-length string rules with spaces normalized.
